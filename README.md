# Assignment Tracker Mobile PWA (TrackIt)

A production-ready, mobile-first Assignment Tracker Progressive Web Application built with React, Vite, Tailwind CSS, Lucide Icons, and `vite-plugin-pwa`.

## Setup & Running

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build and preview PWA:
   ```bash
   npm run build
   npm run preview
   ```
